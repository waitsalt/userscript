# Userscript 集合

浏览器 Userscript 脚本集合，用于自动化和增强网页功能。

## 脚本列表

| 文件夹 | 说明 |
|--------|------|
| [yuque-export](./yuque-export/) | 语雀文档导出工具 - 将语雀文档导出为包含 Markdown 和图片的 ZIP 压缩包 |

## 快速开始

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开对应脚本文件夹中的 `yuque-export.user.js` 文件
3. 复制脚本内容
4. 在 Tampermonkey 中创建新脚本并粘贴内容
5. 刷新目标网页即可激活脚本
